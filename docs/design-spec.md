# PixelMC-Hub · 旅人手册界面约定

## 定位与边界

面向服务器玩家的个人空间，快速查看自己的状态、佩戴称号、阅读收藏。产品名 PixelMC-Hub，中文界面名旅人手册。网页是已确认的设计参考；`minecraft/` 下使用 Skia／Skija 原生绘制制作 Forge 1.20.1 本地客户端实验，不嵌入浏览器，也不直接运行 React／CSS。游戏内效果须在真实客户端验收。

固定演示日期为 2026/11/03，演示玩家为 zhan_cpu。身份 UUID、在线统计、称号条件、登录状态均为假数据。签文与物品插图复用已有 DailyFortunes 素材。浏览器本地存储仅保存展示偏好，不写任何远程服务。

## 视觉

- 浅色液态玻璃方向：蓝紫环境光、半透明侧栏、清晰的白色阅读面。高光和深度集中在彩色玻璃导航、玩家身份卡、称号收藏；不对正文做扭曲或全屏持续着色器动画。
- 主要颜色由 `src/tokens.json` 定义：背景 `#e6eaf8`、白面板 `#ffffff`、正文 `#26344f`、紫色主操作 `#765bd4`、淡紫 `#eee7ff`、签等级金色 `#ae8132`。`styles.css` 保留布局和基础状态，`glass-theme.css` 管理材质与组件集成。
- 使用真实 React Bits GlassIcons、GlassSurface、TiltedCard。导航图标为蓝、紫、橙，支持悬停与按压；侧栏使用带较高乳白遮罩的整块玻璃，身份卡使用柔和磨砂表面和 Minecraft 头像，避免折射在圆角形成尖角杂边。称号卡随指针小幅倾斜并改变高光；外容器允许溢出，圆角裁切只作用于卡片表面，确保放大后边框完整。
- 收藏卡片的细节服务于主题和信息层次：称号主题色的叠层玻璃徽章、品质与类别、分区日期。标题与徽章分别占据卡片两侧，悬停只轻微倾斜；紧凑视图缩减为 68 px 高的收藏行。避免堆砌重复说明。
- 侧栏靠内容区的上、下边角为直角，材质与内容区直接接齐。只有外层窗口负责裁切整体圆角，不在内侧接缝添加弯曲内描边。
- 字体按网页实际顺序匹配：正文 Segoe UI Variable Text → Segoe UI → Microsoft YaHei UI，诗句 Noto Serif SC → Source Han Serif SC → SimSun；不把机器上已有的首选字体跳过，也不伪造粗体。主标题 24–25 px，正文约 12–15 px。像素头像和物品图以清晰边缘显示，不替换为无关摄影素材。
- 控件圆角约 12 px、卡片 22 px、外层 28 px。间距以 4 px 为单位，页面留白约 20–28 px。
- 使用场景是 Java 版游戏内横屏面板；主体最大逻辑宽度 1260 px、最大逻辑高度 850 px，主内容独立滚动。原生版按显示器 DPI 换算（上限 1.75 倍），同时不超过视口宽度的 90% 和高度的 84%；不能把最大化或全屏当成无限放大整个页面。绘制与命中统一使用此缩放。按横屏窗口验收，不以手机竖屏为目标。不能为了固定周数截断月末日期。
- 轻量进入与页面过渡；系统“减少动态效果”和界面设置共同控制 CSS 与组件动效。禁用陀螺仪输入。按开屏频率播放约 3 秒的手写 hello：蓝紫渐变连笔描绘、短暂停留、淡出；然后始终进入个人主页，依次浮现标题、身份卡、下方卡片。开屏时正文不提前播放入场动画，减少动态效果时跳过开屏。
- 立体头像共用同一渲染组件：按 Minecraft 皮肤 UV 读取六面，头部为 8 单位方块，透明帽子层为独立的 9 单位方块，不将外层烘平在正面上。支持现代和旧式比例的皮肤；测试皮肤通过本地环境变量指定，并排除在 Git 外。
- 侧栏保留清晰文字和边缘高光，进一步降低底色和两层乳白遮罩，让背景色透入；不降低整栏透明度，避免文字一起变淡。底部只保留存档信息和设置，省略重复的玩家身份与在线状态。

## 信息与交互

### 个人主页

一体身份卡展示头像、名字、当前称号与当前整合包／存档统计。底部三等分展示在线时长、登录次数、上次登录；上次登录精确到时分秒，与首次加入单独存储，首次加入仅留在个人资料中。问候使用“你好”。UUID 置于个人资料弹窗，避免主视图拥挤。

下方两栏为今日签笺、最近收藏。今日状态必须区分尚未抽签、等待解签、已经解签、已收进藏签匣。未解签不得显示结果；已解但未归档不计入收藏数量。最近收藏和月历跟随同一份可见归档记录。

### 我的称号

左侧收藏，右侧佩戴预览；窄屏预览置于下方。支持已拥有/全部/未获得筛选、搜索、最近获得/名称排序与密度切换。预览区沿用选中称号的主题色，包含玻璃底座、头像与名字；状态标签明确区分“仅预览”和“已佩戴”。获得方式与获得日期分别成组。

选中只是预览，点击佩戴才修改状态。再次点击佩戴按钮可摘下。展示开关与佩戴独立：隐藏不等于摘下。未拥有的称号可查看条件，不允许佩戴。搜索空结果应有清除筛选入口。

称号徽章由管理员配置，玩家不能自行修改。预设定义在 `src/title-icons.js`，称号数据的 `icon` 保存稳定 ID：草木、山野、星光、筑造、月夜、丰收、曙光、云游，以及新增的“个人专属”（`personal`，人像轮廓）。类别文字、品质和图标分别存储，不根据称号名称猜图标，也不把“个人专属”图标当作权限依据。未知 ID 回退为草木图标。

正式接入时，在管理员 WebUI 的称号创建／编辑页增加带名称的图标预设选择器并即时预览，随称号数据保存和同步；收藏卡、预览区及详情使用同一个 ID。当前原型只准备预设与字段约定，尚未实现管理员编辑、服务端持久化或推送。

### 我的签笺

月历和列表共用收藏记录，日期显示到具体时间的历史列表。月历周日至周六，按真实月历生成必要周数，未来日期不可选。无签时显示淡化签笺，已有签以等级色从左上到右下柔和过渡；不能使用生硬的纯色斜切。

左侧月历使用清晰的月份与本月收藏数；右侧暖色纸面展示诗文摘要，阅读按钮位于纸面下方，手册展示卡紧接阅读卡。月历卡与右侧整列上下边缘对齐，日期行均匀分配剩余高度；切换历史月份优先选中该月最近一张收藏。上月从左侧、下月从右侧短距离滑入并渐显，控件本身不移动。展开后阅读解签，没有收藏显示原因和存签方式。

页面中的“手册展示”只是本地展示选择；游戏世界中藏签匣上方的悬浮签保持游戏内设置，不在原型中伪造远程成功。已展示当前选择或选择无签日期时禁用重复操作。

### 设置、反馈与可访问性

关闭按钮和 Esc 收起面板，预览中 Esc 可重新打开。弹窗优先响应 Esc，限制焦点在弹窗内并在关闭时归还。控件必须有键盘焦点、图标按钮名称、状态反馈。提示从上方短暂滑入，不弹出阻塞确认框。

界面设置只含当前具备效果的选项。开发用状态切换位于面板外的“预览选项”，不得混入未来正式游戏界面。当前没有玩法指南入口。

开屏频率采用三档滑块，从左到右按频率递增：仅初次 → 每次登录 → 每次打开。可拖动、点击文字或使用方向键选择，默认“每次打开”位于最右端；按稳定 ID 保存选择，调整排列不改变已有设置。

- 仅初次（`once`）：仅首次打开时播放，已展示记录持久化；切换档位不会清除记录，也不立即触发开屏。已在其他档位看过也算已展示。
- 每次登录（`login`）：每次进服后首次打开时播放，同次登录内收起再打开不重播。浏览器原型以一次页面加载模拟一次登录，刷新页面开始新登录；原生客户端由游戏登录／离服事件界定，不能随 Screen 重建重置。
- 每次打开（`always`）：每次打开手册均播放。

减少动态效果优先于频率选择，跳过时不记作已展示；关闭减少动态效果后从下次打开起按原档位执行。设置及首次展示记录当前保存在浏览器，正式接入后按玩家与服务器／存档隔离并持久保存，不随预览演示数据还原而清除。

## 未来接入

只有服务器确认后才展示真实在线状态、归档与佩戴结果。按玩家 UUID 和服务器/存档身份隔离缓存；退出、重连、请求超时均应有状态。插件仅注册自己的个人功能和数据，不向客户端开放 Manager 管理接口或数据库凭据。

优先核对 Minecraft 的 GUI 缩放、中文字体、键盘/鼠标焦点与模组兼容。届时重新验收实际游戏效果，不把浏览器验证当作游戏内验收。
