# 旅人手册 · 第一版界面约定

## 定位与边界

面向服务器玩家的个人空间，快速查看自己的状态、佩戴称号、阅读收藏。当前实现是浏览器中的交互样稿；未来可作为游戏内绘制与输入适配的参考，不能把 Web 源码直接视为已经完成的 Minecraft 界面。

固定演示日期为 2026/11/03，演示玩家为 zhan_cpu。身份 UUID、在线统计、称号条件、登录状态均为假数据。签文与物品插图复用已有 DailyFortunes 素材。浏览器本地存储仅保存展示偏好，不写任何远程服务。

## 视觉

- Fluent 2 浅色方向。外部灰绿环境、白色内容面板、轻微着色的侧栏；以间距、层次和细边框组织信息，避免大量发光与模糊效果。
- 主要颜色由 `src/tokens.json` 定义：背景 `#edf2ef`、白面板 `#ffffff`、正文 `#24352e`、主操作 `#28735f`、淡绿 `#e7f1ec`、签等级金色 `#ac8137`。
- 界面使用 Segoe UI / Microsoft YaHei UI，诗句局部使用宋体。主标题 24–25 px，正文约 12–14 px，辅助信息分层处理。像素头像和物品图以清晰边缘显示。
- 控件圆角 8 px、卡片 14 px、外层 20 px。间距以 4 px 为单位，页面留白约 24–32 px。
- 桌面主体最大宽度 1260 px；主内容独立滚动。窄屏先垂直重排，手机改为底部导航。不能为了固定周数截断月末日期。
- 轻量进入与页面过渡，140–360 ms；系统“减少动态效果”和界面设置均可关闭。首次开屏动画另行设计，本版不添加等待画面。

## 信息与交互

### 个人主页

一体身份卡展示头像、名字、当前称号与当前存档统计（在线时长、登录次数、首次加入）。UUID 置于个人资料弹窗，避免主视图拥挤。

下方两栏为今日签笺、最近收藏。今日状态必须区分尚未抽签、等待解签、已经解签、已收进藏签匣。未解签不得显示结果；已解但未归档不计入收藏数量。最近收藏和月历跟随同一份可见归档记录。

### 我的称号

左侧收藏，右侧佩戴预览；窄屏预览置于下方。支持已拥有/全部/未获得筛选、搜索、最近获得/名称排序与密度切换。

选中只是预览，点击佩戴才修改状态。再次点击佩戴按钮可摘下。展示开关与佩戴独立：隐藏不等于摘下。未拥有的称号可查看条件，不允许佩戴。搜索空结果应有清除筛选入口。

### 我的签笺

月历和列表共用收藏记录，日期显示到具体时间的历史列表。月历周日至周六，按真实月历生成必要周数，未来日期不可选。无签时显示淡化签笺，已有签以等级色从左上到右下柔和过渡；不能使用生硬的纯色斜切。

选择日期展示诗文摘要，展开后阅读解签。没有收藏显示原因和存签方式。页面中的“手册展示”只是本地展示选择；游戏世界中藏签匣上方的悬浮签保持游戏内设置，不在原型中伪造远程成功。

### 设置、反馈与可访问性

关闭按钮和 Esc 收起面板，预览中 Esc 可重新打开。弹窗优先响应 Esc，限制焦点在弹窗内并在关闭时归还。控件必须有键盘焦点、图标按钮名称、状态反馈。提示从上方短暂滑入，不弹出阻塞确认框。

界面设置只含当前具备效果的选项。开发用状态切换位于面板外的“预览选项”，不得混入未来正式游戏界面。当前没有玩法指南入口。

## 未来接入

只有服务器确认后才展示真实在线状态、归档与佩戴结果。按玩家 UUID 和服务器/存档身份隔离缓存；退出、重连、请求超时均应有状态。插件仅注册自己的个人功能和数据，不向客户端开放 Manager 管理接口或数据库凭据。

优先核对 Minecraft 的 GUI 缩放、中文字体、键盘/鼠标焦点与模组兼容。届时重新验收实际游戏效果，不把浏览器验证当作游戏内验收。
