# PixelMC-Hub native prototype assets

Artwork is copied byte-for-byte from public/assets, with the original source attribution preserved in licenses/ORIGINAL-NOTICE.md. The collection chest, fortune barrel, fortune slip and all sixty fortune texts retain AGPL-3.0-only; full text is in licenses/AGPL-3.0-assets.txt. The PixelMC brand logo is user-provided and is not relicensed. The avatar is the MemorialTitles bundled demo placeholder. No private local-preview/player-skin.png is packaged.

White transparent PNG icons are rasterized at 192 by 192 from installed lucide-react 0.468.0 SVG components, retaining the ISC copyright and permission text in licenses/LUCIDE-ISC.txt. They use the web UI's original 24-unit shape and 2-unit round strokes. No image generation or external image service is used.

Demo JSON retains the web prototype's fictitious player, titles, dates and archive; it is not production player data. ASSET-MAPPING.json records original paths, native paths and SHA-256 hashes. System fonts are referenced at runtime and are not distributed. Original tooling and HubHead code are Apache-2.0.
